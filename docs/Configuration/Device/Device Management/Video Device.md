#### Introduction to Video Device

Edit in Configuration-》Device-》Device Managemen-》Video Device.

![](.\Img\VideoDevice.png)

| Number | Name         | Function                 |
| ------ | ------------ | ------------------------ |
| 1      | Name         | Device name              |
| 2      | User Name    | Device Username          |
| 3      | Password     | Device password          |
| 4      | IP           | Device IP address        |
| 5      | Port         | Device SDK port          |
| 6      | Audio        | Whether to turn on audio |
| 7      | Sandbox      |                          |
| 8      | Max Channels |                          |
| 9      | Buffertime   |                          |
